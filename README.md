## 🎓 Student ID Card Generator

A responsive web application that allows students to generate professional digital ID cards instantly. Users can enter their personal details, upload a photo, customize card themes, generate QR codes, and download their ID card as an image.

## 🚀 Features

* Upload and preview student photograph
* Generate personalized student ID cards
* Automatic QR code generation for student verification
* Multiple card themes (Purple, Blue, Red, Green)
* Roll number validation
* Date of birth validation
* NMAMIT email validation (`@nmamit.in`)
* Download ID card as PNG image
* Save student cards using Local Storage
* Edit and delete previously saved cards
* Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* QRCode.js
* HTML2Canvas

## 📋 Student Information Included

* Full Name
* Roll Number
* Email Address
* Date of Birth
* Department
* Year of Study
* Blood Group
* Student Photograph
* QR Code Verification

## 🎨 Available Themes

* Purple
* Blue
* Red
* Green

## 📸 How It Works

1. Upload a student photo.
2. Enter student details.
3. Select department and year of study.
4. Choose a card theme.
5. Click "Generate ID Card".
6. Preview the generated card.
7. Download the card as an image.

## 💾 Data Storage

Student records are stored locally in the browser using Local Storage, allowing users to:

* Save multiple ID cards
* Edit existing cards
* Delete unwanted cards
* Restore previously generated cards

## 🎯 Project Objective

This project was developed to simplify the process of creating digital student identity cards while providing an attractive, user-friendly interface and instant card generation capabilities.
